# Clean_EveryDay

Full-stack E-Commerce & Home Cleaning Service Application.

## Project Structure
- **Server**: Express.js REST API (Node.js) with MongoDB, Firebase, Cloudinary, and Nodemailer.
- **customer-frontend**: React + Vite customer-facing application.
- **admin-frontend**: React + Vite admin dashboard application.

## Deployment on Vercel
Each folder (`Server`, `customer-frontend`, `admin-frontend`) is configured with its own `vercel.json` for independent deployment on Vercel.
